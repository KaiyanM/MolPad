Pattern of Selected Groups

Network Navigation

  1. Select a functional annotation on the top left. Nodes turn bright green when more of their features carry that annotation. Lower the importance score to show weaker connections.
  2. Drag a rectangle on the network, or click nodes, to select clusters. The stacked bar, the pattern plot and the table update to the selection. Use the taxonomic scope box to focus on specific taxa.
  3. Browse the annotated features of the selected clusters in the table. Database ids link to their online records. Filter by annotation, search, sort by clicking a header, or change the page size. The small button next to each column name opens a menu to sort that column and to filter it by searching and ticking its values.

This page is a static file: every filter runs in your browser, so you can share the file as is.
