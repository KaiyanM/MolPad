CARD example: the question names two or more classes (level 2) and asks how each behaves or whether
they differ, without naming clusters ("Do X and Y peak at different weeks?"). One example cluster is
shown per class. kind=example, example_by=level2_composition (the cluster whose features are mostly
that class). The classes are already in the level-2 filter.
